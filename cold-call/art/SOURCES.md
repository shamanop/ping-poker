# Cold Call: placeholder art sources

These are PLACEHOLDERS for milestone 4 so the game is playable before Chris picks an art style (concept stills in `concepts/`).
The final art replaces them through `public/games/coldcall/assets/symbols.json` (a file swap, no code change).

|---|---|---|
| cash, pile, rx, headset, can, mug, note, ball, closer, phone, quote, upsell, hero (.svg) | Twemoji 15.0.0 (npm `@twemoji/svg`, github.com/jdecked/twemoji) | Graphics CC-BY 4.0, (c) Twitter, Inc and other contributors. Attribution is given here and in the game's info panel. |
| bg.svg | Drawn by hand for this project (gradient + faint grid) | Project code licence |

note = 1f4dd, ball = 1f3be, closer (wild) = 1f911, phone = 260e, quote = 1f4ac, upsell = 1f6d2 (cart), hero = 1f9d1-200d-1f4bc (office worker).
Imagery is cartoonish only: no brands, no real drug names, nothing instructional.
