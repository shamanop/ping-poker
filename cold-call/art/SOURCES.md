# Cold Call: placeholder art sources

These are PLACEHOLDERS for milestone 4 so the game is playable before Chris picks an art style (concept stills in `concepts/`).
The final art replaces them through `public/games/coldcall/assets/symbols.json` (a file swap, no code change).
