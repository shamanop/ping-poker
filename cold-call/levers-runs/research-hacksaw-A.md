### Le Bandit: staging, teases and persistence

**Persistence between spins**
- Base game: Golden Squares built by wins persist through cascades within the spin and are cleared after Rainbow activation ("Golden Squares are then removed", Bigwinboard https://www.bigwinboard.com/le-bandit-hacksaw-gaming-slot-review/). oddsforward: "Squares created early in a cascade sequence persist through subsequent cascades within the same spin" https://oddsforward.com/games/le-bandit
- Luck of the Bandit: squares "remain highlighted between spins until they are activated by a Rainbow" https://www.hacksawgaming.com/games/le-bandit
- All That Glitters Is Gold and Treasure at the End of the Rainbow: squares stay lit all bonus, even after activation, can be activated again https://www.hacksawgaming.com/games/le-bandit
- No cross-spin meter in base game: Bigwinboard: "this doesn't mean collecting winning symbols in a meter" https://www.bigwinboard.com/le-bandit-hacksaw-gaming-slot-review/

**Cascade rule (Super Cascade)**: all contributing symbols "plus any matching types visible on the reels" vanish https://www.hacksawgaming.com/games/le-bandit

**Tease / near-miss staging**: no review site or Hacksaw page describes it in words ("not published" as prose). Primary evidence taken from the game client itself (public demo bundle, minified; my reading, treat as engine behaviour not marketing copy):
- Source: https://static-live.hacksawgaming.com/1309/1.25.0/main.js (Le Bandit = gameid 1309, version from https://static-live.hacksawgaming.com/1309/version.json = 1.25.0, activation 2026-09-23). Page title in demo index is "Le Bandit".
- The slot engine has a per-reel "attention" system: when a reel is flagged as attention, `slowdown(index, duration)` is called, the reel gets `attention=true`, publishes `reelSlowed`, and its speed is interpolated from full speed toward `attentionSpeed` over `slowdownDuration` (code: `speed=1-Q+attentionSpeed*Q`). Slowdown is skipped when `quickStop` is set. Later reels are delayed by `attentionDuration*(n+1)` per reel after the first attention reel, so the reveal becomes sequential left to right once a tease starts.
- The attention filter counts matching symbols in the reel/row or in the whole grid (`included = (count in line == t) || (total count == e)`), and symbols considered are the scatter ids. The numeric thresholds (how many FS symbols must already be on screen to slow the next reel) were not found in the client bundle: not published.
- Engine default spin timings in the same bundle (hacksaw.slotcommon SpinValues; the game might override, not confirmed): normal start 0.5 s, stop 0.66 s, speed 1, reelDelay 0.01 s, attentionSpeed 0.6, presentDelay 0.5 s; turbo start 0.2 s, stop 0.2 s, speed 1, reelDelay 0.01, attentionSpeed 0.6, presentDelay 0.5 s; superTurbo start 0.2 s, stop 0.05 s, speed 30, reelDelay 0, attentionDuration 0, presentDelay 0. Source: same main.js URL.
- Sound events (embedded JSON in same main.js): `scatterStopped` plays "bonus_landed" for the FS scatter (symbol id 12) and "rainbow_ding" for the Rainbow (symbol id 13), volume 0.3, random pitch -100..+100; `scatterComplete` plays "bonus_triggered" (volume 0.1, 0.05 s delay); a looping "rainbow_idle" while a Rainbow sits on the grid (events `rainbowIdle` / `stopRainbowIdle`); `activateRainbow` -> "rainbow_activate"; `takePhoto` -> "camera_drum" (the Polaroid scatter); `spawnPot` -> "cash_register"; `spawnClover` -> "clover_reveal"; `updatePotCounter` -> "count_blip"; `coinVortex` -> "swirling_swoosh"; `collect` -> "coins_pour"; `removeSymbols` -> "poof"; `strapLeprechaunHat` -> "slap". There are six raccoon voice pools: welcoming, raging, infuriating, fuming, happy, delighted (character reacts to outcomes). Same URL.
  - So "bell" in the brief maps to: "rainbow_ding" per Rainbow landing (pitch-randomised ping) and "bonus_landed" per scatter landing.
- Win tier ladder in the client: enum `WinLevels` = Small, Regular, BigWin, MegaWin, SuperMegaWin, EpicWin. Sound by tier level: levels 0-2 none, 3 "coins", 4 "fanfare_1", 5 "fanfare_2", 6 "fanfare_3", 7+ "fanfare_4". End-of-win sound "win_end_bet_low" when total win <= 1.0x bet, "win_end_bet_over" above. Same URL. The x-bet thresholds for each tier: not published (not in client bundle; likely supplied by the server).
- Game music has four modes: base, and three feature modes (`enterMode` plays basegame_music then bonus_music x3); ambience "city_ambience" in base, "city_ambience_night" in bonus, "ambience_nature" in the epic bonus. Same URL.
- Respinix notes the soundtrack shifts in bonus to an "upbeat Irish jig" https://respinix.com/demo/le-bandit/ ; Bigwinboard/oddsforward describe "jaunty accordion-led French cafe theme", brass swell in free spins https://oddsforward.com/games/le-bandit (editorial, unreliable).

## Cross-game pattern (all four, from the sources above)
- Every Hacksaw game page lists four RTP variants roughly 96.3 / 94.3 / 92.3 / 88.3 (Le Bandit 96.34 / 94.23 / 92.17 / 88.36; WDW 96.38 / 94.55 / 92.33 / 88.42; CC2 96.27 / 94.22 / 92.41 / 88.28; RIP 96.22 / 94.27 / 92.32 / 88.02). - Buy RTPs sit in a tight band around the base RTP (Le Bandit 96.28 to 96.4; CC2 96.22 to 96.35; RIP 96.2 to 96.44; WDW 96.27 to 96.43), i.e. buying a bonus does not cost a worse RTP; the 3x/5x BonusHunt-style bet mode is the standard cheap mode: Le Bandit 3x for 5x odds, RIP 3x for 5x odds, CC2 5x for 10x odds. Sources: tables above.
- Hit frequency scales with volatility: Le Bandit 32.47% (3/5), CC2 27 to 27.6% (5/5), WDW 19.3 to 19.36% (4/5), RIP 18 to 18.22% (3/5).
- Max win probability, where published: CC2 1 in 1.7M (20,000x), RIP 1 in 6M (12,500x), WDW ~1 in 6M (12,500x, Respinix only), Le Bandit 1 in 14M (10,000x).
